脚本（VScript）是起源引擎在《求生之路2》中首次引入的新系统，是一种用于脚本编程的虚拟机。它是一个强大的自定义系统，允许我们实现各种高级功能。

7.1 VScript#

VScript，在《求生之路2》中首次引入，在后来的更新中被移植回了《军团要塞2》，是一种用于脚本编程的虚拟机，它在起源引擎和起源2引擎与外部脚本之间充当一个抽象的绑定层。

根据Alien Swarm - SDK（异形丛生-SDK）我们可以推知，以下的脚本语言已经或者在不久的将来能够得到支持：Squirrel、Lua、Gamemonkey、Python。

脚本文件放置于游戏目录内的scripts/vscripts/文件夹中。

7.1.2 VScript到底意味着什么？#

VScript，也就是游戏里为创作者提供一套脚本系统，可以让创作者在代码允许的情况下实现更高自由度的创作。我们知道，游戏本来也是代码写的，那自然用代码来写、为自己的地图新增功能是理所应当的。

VScript的存在让我们可以直接通过官方的各种API来直接与游戏交互，而游戏能够直接读取这些脚本来运行我们所想要的代码，自然能够实现许多功能，而不仅仅只是局限于游戏内的各种实体。因为实体没有的功能，我们可以代码写出来呀。实体本质上也是内置于游戏引擎内的一套代码。

所以直接掌控代码当然是自由度最高的方式，VScript进一步解放了创作者的创造力。

7.2 Squirrel#

Squirrel是一个类似Lua的编程语言，但使用类似C语言的语法。在起源引擎中，Squirrel是VScript采用的脚本编程语言之一。

Squirrel是一种高级的命令式面向对象编程语言，旨在成为一款功能强大的脚本工具，满足游戏等应用程序在规模、内存带宽和实时性方面的要求。Squirrel 提供丰富的特性，例如动态类型、委托、高阶函数、生成器、尾递归、异常处理和自动内存管理，同时将编译器和虚拟机集成到约 6000 行 C++ 代码中。

Squirrel语言的官方文档（英语）：

http://squirrel-lang.org/doc/squirrel3.html（3.0版本文档）

http://www.squirrel-lang.org/squirreldoc/reference/index.html（3.2版本的文档）

3.2版本的文档界面更友好，且两个版本无较大差异，基本通用，故推荐看3.2版本的文档。

Squirrel语言广泛使用一种名为表（table）的关联数组数据结构。表的键和值几乎可以包含任何类型的变量。脚本执行环境由嵌套表组成，当执行脚本时，其变量和函数会作为表的槽（slots）添加到表中。

printl("Hello World"); // 语句可以以分号结束……
printl("Hello World")  // ……或者以换行符结束

Squirrel的语法类似于C/C++/Java等语言，但它具有类似Python/Lua等语言的动态特性。语句可以用换行符或分号（;）分隔（在switch/case语句中也可以用关键字case或default分隔），如果语句后面跟着}，这些符号是可以省略的。

求生之路2使用的Squirrel版本是3.0.4。

本节只作简单介绍，详细的内容请到Squirrel的官方文档了解。

7.2.1 文件格式#

  • 1.
    变量（variables）

Squirrel 主要有两种类型的变量：表槽（table slots）和局部变量（local variables）。这与类型无关；就像 Python 一样，任何变量可以在任何时候是任何数据类型，无需类型声明。由于执行作用域始终是一个表，任何在函数外部声明的变量都会成为表槽。

  • （1）
    表槽

表槽需要使用 <- 操作符声明。这些变量用于在函数结束后依然需要保留的值。一旦表槽被创建，就可以使用 = 或 <- 操作符重新赋值。= 操作符在表槽不存在时会抛出异常，因此在需要重新赋值（而非创建新表槽）时应优先使用。

  • （2）
    局部变量

使用 local 关键字声明，只能在其定义的作用域内（通常是其所在的花括号范围）访问。这类变量用于临时或辅助的用途，后续可以被丢弃。例如一个典型的 for 循环：

for (local i = 0; i < 20; i++) {
    // 循环逻辑
}
  • （3）
    全局变量

全局变量实际上是根表［getroottable()］中的表槽。可以使用 :: 作用域操作符声明，也可以通过带或不带 :: 的方式访问。

  • （4）
    常量

使用 const 关键字声明，用于运行时不会改变的值，例如圆周率 Pi 或表示文件路径的字符串。由于常量是编译期特性，其值在编译期计算，因此只能是整数、浮点数或字符串。试图为常量赋新值会导致编译时错误「can't assign expression」。可以想象，Squirrel 在编译时将代码中每个常量标识符的出现替换为当前值，因此无法重新赋值。

常量可以在代码中多次用不同值声明。在运行时，可以通过 getconsttable() 获取编译期间定义的所有常量表。随着新代码的编译，常量表会更新。值得注意的是，常量表及其值在行为上与普通表槽相同，并没有通常意义上的保护机制。

注意事项

local 和 const 变量必须用 = 操作符声明，使用 <- 会导致编译时错误。

示例代码：

a <- 5               // 在当前表中创建表槽
b <- "A text string" // 在当前表中创建表槽
::x <- 10            // 在根表中创建表槽
local i = 0          // 初始化一个临时变量
const E = 2.71828    // 创建一个常量
b = "New string"     // 修改现有表槽
x = 11               // 修改现有表槽

检测表槽是否存在

可以使用 in 操作符检查表槽是否存在，也可以通过以下代码实现：

try {a} catch (e) { /*...*/ }

示例代码（假设在与上述代码相同的环境中执行）：

"a" in this  // true
"x" in this  // false，除非处于根表中
"i" in this  // false，局部变量不是表槽
"E" in this  // false，除非处于常量表中
delete a     // 删除表槽
"a" in this  // false，表槽不再存在

7.2.2 数据类型#

Squirrel 是一种动态类型语言，任何变量都可以被赋予任何类型的值。

注意：

VScript API 函数是与 Source C++ 代码的绑定，因此尽管看似可以将任何类型的值传递给它们，但它们只接受特定类型的值。

内置函数 typeof 返回输入值的类型，并以小写字符串形式表示，例如 typeof(5) == "integer"。

类型描述
Integer整数范围为 -2147483648 到 2147483647，即 -231 到 231-1。
注意：在 64 位游戏中，如《Team Fortress 2》，整数大小为 64 位，这意味着它们表示的范围为 -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807。
续表
类型描述
Float范围为-3.4028235e38到3.4028235e38，即 -3.4028235×1038到 3.4028235×1038。
在代码中，通过添加小数点，数字变成浮点数。1.0 和 1. 都是合法的，而 .0 或 0f 会导致编译错误。
对于正无穷大（+infinity）、负无穷大（-infinity）和 NaN（即Not a Number）没有常量表示，但 1.0/0.0、-1.0/0.0 和 0.0/0.0 会分别计算为这些值。
当通过<float>.tostring()或 format("%f", <float>) 转换为字符串时，它们分别变为：1.#INF、-1.#INF 和 -1.#IND；inf、-inf 和 nan。
String不可变字符串，类似于 C 字符串，支持转义序列（如 \t, \a, \b, \n, \r, \v, \f, \\, \", \', \0, \xhhhh）。这些序列在逐字面量字符串中不会起作用。
Null空值数据类型，只有一个值 null。
Bool布尔数据类型，可以是 true 或 false。
Table关联数组。
Array可变的 C 风格数组。
Function支持二阶函数，因此可以将函数作为值赋给变量。
Class面向对象的类，类似于表的实现。
Class Instance类的实例对象，游戏生成的脚本句柄也被视为实例对象。
Generator可以挂起并恢复执行的函数。
Userdata游戏使用的透明数据。
Thread协程实例，类似于生成器，但具有自己的执行栈。
Weak reference弱引用，当所指向的对象被销毁时，弱引用会被设置为 null。
  • 1.
    布尔值 (Bool)

Squirrel 认为 null、0（整数类型）和 0.0（浮点类型）是 false，任何其他值都被认为是 true。这允许你例如使用 if (var) 来进行变量的 null 检查。

警告：如果整数或浮点数可能是 0 或 0.0，请不要像这样进行 null 检查。显然，这与内置字符串函数 find(<substring>) 相关，该函数返回找到的子字符串的索引或 null。请改用 if (var == null)。
if (false) { /* ... */ } // 不执行
if (null)  { /* ... */ } // 不执行
if (0)     { /* ... */ } // 不执行
if (0.0)   { /* ... */ } // 不执行
  • 2.
    表 (Tables)

表是关联数组，意味着它们包含一组键值对，称为槽（slots）。可以使用键索引表，返回关联的值。键和值可以是任何数据类型（键不能是 null），包括其他表，这允许创建更复杂的数据结构。

表通过花括号 {} 来定义。在表定义内部，可以使用 key1 = value1, key2 = value2, ... 模式来定义槽。表定义外部，可以使用 table.key <- value 模式向现有表添加新槽。

使用 . 运算符索引键仅在键为字符串或数字字面量时有效。数组样式的索引 table[keyVariable] 可以用于索引任何类型的键。

提示：一些内置的表函数包括 len() 和 clear()。
// 表定义。键值对之间的逗号是可选的，
// 如果存在空格。但是，如果下一个键在方括号内，则必须使用逗号。
myTable <-
{
 a = 3               // 键: "a", 值: 3
 b = 7,              // 键: "b", 值: 7
 [6] = "six"         // 键:  6 , 值: "six"
 func = function()   // 键: "func"
 {
  return a + b
 }
 nestedTable =       // 键: "nestedTable"
 {
  z = "a string"
 }
}
// 或者：
myTable <- {}
myTable["a"] <- 3     // 字符串键可以这样索引...
myTable.b    <- 7     // ...有两种方式
myTable[6]   <- "six" // 数字必须这样索引
myTable.func <- function() { return a + b }
myTable.nestedTable <- { z = "a string" }
// 遍历一个表：
// 'key' 和 'value' 是任意的
foreach (key, value in myTable)
{
 printl(key + ": " + value)
}
// 打印的顺序可能有所不同！
// a: 3
// func: (function : 0x00000000005AD280)
// b: 4
// 6: six
// nestedTable: (table : 0x000000000069D130)
// 'in' 运算符检查的是键，而不是值：
printl("a" in myTable) // 打印 "true"
printl(3 in myTable)   // 打印 "false"
printl(myTable.func()) // 打印 10 (a + b)
// 每个表都有一个内置的长度函数：
printl(myTable.len())  // 打印 5
delete myTable.a  // 删除键值对 a=3
  • 3.
    数组（Arrays）

数组是按数字索引的对象序列，从0开始。语法上，它们与C语言中的数组类似，但与C语言数组不同，Squirrel中的数组是可变的，可以通过一组内置函数插入和移除值。

数组使用方括号定义。

警告：不能使用in运算符来测试某个值是否在数组中，因为在Squirrel中，数组是表格，其中键是索引。in运算符会查找数组的索引，而不是其值。
提示：一些内置的数组函数有：len()，clear()，append(<value>)，insert(<index>, <value>)，remove(<index>)，reverse()，sort([func(a,b)])。

在Squirrel 3.x中，还有更多可用的函数，包括find(<value>)，map(<func(a)>)，slice(<start>, [end])。

// 数组定义。如果值之间有空格，逗号是可选的。
myArray <-
[
 7,        // 键：0，值：7
 "text",   // 键：1，值："text"
 null      // 键：2，值：null
]
// 或者：
myArray = [4, "text", null]
// 或者：
myArray <- []
myArray.append(7)
myArray.append("text")
myArray.append(null)
// 或者：
myArray <- array(3)
myArray[0] = 7
myArray[1] = "text"
myArray[2] = null
// 遍历数组：
// 'i' 和 'value' 是任意的
foreach (i, value in myArray)
{
 printl(i + ": " + value)
}
// 或者：
for (local i = 0; i < myArray.len(); i++)
{
 printl(i + ": " + myArray[i])
}
// 打印：
// 0: 7
// 1: more text
// 2: null
// 'in' 运算符检查的是索引，而不是值：
printl(   2   in myArray) // 打印 "true"
printl("text" in myArray) // 打印 "false"
printl(myArray.len())     // 打印 3
myArray.remove(0)   // 移除索引0的元素
   // 并重新排列所有其他索引
  • 4.
    函数（Functions）

Squirrel 中的函数与 C 语言中的函数类似。它支持二阶函数，因此可以像其他值一样直接操作函数，包括将其存储在变量和表槽中。此外，还支持默认参数值和可变数量的参数。

有关详细信息，请参阅Squirrel API文档上有关函数的介绍a。

命名函数时通常以大写字母开头。

// 定义函数。
// 注意：函数就像变量一样，由名称和值组成，其中值包含关键字「function」。
Greet <- function()
{
 printl("Hello!")
}
someTable <-
{
 Greet = function()
 {
  printl("Hello!")
 }
}
// 函数也可在局部定义：
local GreetLocal = function()
{
 printl("Hello!")
}
// 使用「()」（括号）调用这些函数。
// 这些函数都会打印「hello」：
Greet()
someTable.Greet()
GreetLocal()
// 出于便利，存在另一种语法来定义函数。
// 所有这些和上面的代码的效果都是一样的。
// 另外，如果只有一个语句，则括号「{」和「}」是可选的。
function Greet()
{
 printl("Hello!")
}
someTable <-
{
 function Greet()
 {
  printl("Hello!")
 }
}
local function GreetLocal()
{
 printl("Hello!")
}
// 更简短的版本：local function GreetLocal() printl("Hello!")
// 这些函数都会打印「hello」：
Greet()
someTable.Greet()
GreetLocal()

调用函数时，可以使其能够或必须接收输入值，这些输入值决定了函数的副作用和/或返回值。

注意：函数定义中，多个参数必须用逗号分隔：function Test(a, b, c, d = 4, e = 5) {...}。对于函数调用，空格即可代替逗号：Test(6,7,8) == Test(6 7 8)。
注意：所有没有默认值的参数必须先排序。
提示：1.为了避免异常，检查参数是否为null通常是一个好主意。 2.由于参数不受类型限制，因此可以使用 typeof 函数以不同的方式处理不同的类型。
提示：通过在最后一个参数中指定「...」，函数可以拥有可变数量的参数。在函数体中，变量 vargv 可用，其行为类似于普通数组。
注意：在 Squirrel 2.x 中，vargv 是一个伪数组，其行为与普通数组不同。每次出现它时，都必须用一个数字作为索引，例如 vargv[0]。它的长度存储在另一个名为 vargc 的变量中，然而该变量在 Squirrel 3.x 中不存在，因此代码不兼容。
// Squirrel 3.x
varArgFunction <- function(delimiter, ...)
{
 foreach (i, arg in vargv)
  print(i + delimiter + arg + "\n")
}
varArgFunction(" : ", 4, null, "string")
// prints:
// 0 : 4
// 1 : null
// 2 : string
// Squirrel 2.x
varArgFunction <- function(delimiter, ...)
{
 for (local i = 0, i < vargc; i++)
  print(i + delimiter + vargv[i] + "\n")
}
varArgFunction(" : ", 4, null, "string")
// prints:
// 0 : 4
// 1 : null
// 2 : string

函数以可选的 return 语句结尾，该语句也可以返回一个值。你可以将返回值想象成「插入」到函数调用的位置。如果函数中未指定返回值，则返回值为 null：

function IsEven(n)
{
 if (n % 2 == 0)
  return true
 else
  return false
}
// alternatively:
IsEven <- function(n) return n % 2 == 0
if (IsEven(42)) // (42 % 2 == 0) == true
{
 printl("42 is even!")
}

从 Squirrel 3.x 开始，lambda 表达式（lambda expression）被引入，它是一种更方便的方式来定义一个只返回单个表达式的函数。当需要将一个函数作为其他函数（例如 array.sort 或 array.map）的参数时，lambda 表达式尤其有用：

local func = @(a,b) a - b // == function(a,b) { return a - b }
printl( func(17,9) ) // prints 8
local arr = [1,5,4,6,2,3]
arr.sort(func)
// arr == [1,2,3,4,5,6]
arr = arr.map( @(x) x * x ) // == function(x) { return x * x }
// arr == [1,4,9,16,25,36]
  • 5.
    生成器（Generators）

生成器a是一类特殊函数，其代码中包含关键字yield。该关键字会暂停生成器函数的执行，并能向恢复其执行的函数返回某个表达式的值。

对于某个生成器g，可通过表达式resume g恢复其执行；该resume表达式的返回值，即为生成器函数上次暂停时通过yield产出的值。而生成器本身的返回值则无关紧要。

生成器可用于foreach语句中，在此场景下无需手动编写resume语句。这种用法下，生成器具备显著优势：它能「即时」（just in time）计算出下一个要产出的值。与之相比，若遍历预先计算好的数组（array）或表（table），且因某些原因在遍历完所有元素前就提前结束（例如循环提前中断），那么之前为数组 / 表中未遍历元素所做的计算就会变成「无用功」，这种遍历方式的劣势便会凸显。

此外，生成器理论上可产出无限多个值，而数组和表能存储的值的数量则是有限的。

function PowersOfTwo()
{
 for (local n = 1; true; n *= 2)
  yield n
}
local x = 100
// 将 x 设置为大于或等于 x 的最小 2 的幂：
foreach (i,pow in PowersOfTwo())
{
 if (pow >= x)
 {
  x = pow
  break
 }
}

包含yield语句的函数被称为「生成器函数」（generator function）。调用生成器函数时，它并不会执行函数体，而是返回一个新的、处于暂停状态（suspended）的生成器（generator）。在返回的生成器「存活」（alive）期间，可以通过resume语句恢复其执行。

yield关键字的作用是暂停生成器的执行，并且可以选择将某个表达式的结果返回给恢复该生成器执行的函数。当生成器返回时，它会进入「终止状态」（die）；生成器返回的情况有两种：一是执行显式的return语句，二是退出函数体。此外，若生成器在运行过程中发生未处理的异常（或运行时错误，runtime error），也会自动终止。处于终止状态的生成器无法再通过resume恢复执行（如代码2所示）

生成器也可通过foreach语句进行迭代。当foreach对生成器进行求值时，会在每次迭代中恢复生成器的执行，直到生成器返回为止。需要注意的是，生成器通过return语句返回的值会被忽略。

注意：处于暂停状态的生成器，会对其局部变量中存储的所有值持有「强引用」（strong reference），但对this对象仅持有「弱引用」（weak reference）。而处于运行状态的生成器，对this对象同样持有强引用。

    类（Class）

Squirrel 实现了一种类似于 Java/C++ 等语言的类机制，但由于其动态特性，它在几个方面有所不同。类是像整数或字符串一样的一等对象，可以存储在表槽、局部变量、数组中，并作为函数参数传递。

7.3 求生之路2脚本#

《求生之路2》的VScript是运行在游戏内虚拟机中的服务器端脚本。它们使用Squirrel编写，Squirrel是一种类似于Lua的编译型脚本语言。该虚拟机目前运行的是Squirrel 3.0.4版本。

7.3.1 主要用途#

  • 1.
    导演脚本（Director Script）

在《求生之路2》中，VScript 最常见的用途是临时影响 AI 导演的行为。这些脚本的功能多种多样，从简单的调整感染者生成和禁止 Boss 感染者出现，到自定义事件（例如突袭和挑战），甚至是复杂的场景化恐慌事件和完全自定义的结局。官方战役中的大多数事件主要都是通过这种方式实现的。
