气体存储元件

1k / 4k / 16k / 64k / 256k 五档 ME 气体元件，1 AE byte 存储 1,000 GU。

ME 气体接口

网络背后是一只真实的 CCB 缓冲罐，支持导入 / 导出 / 双向 / 关闭与可调供给压力。

气体 P2P 隧道

像普通 P2P 一样把气体送到网络的另一头，每个面都是一只真实的小压力容器。

原生设备互通

AE2 的输入 / 输出 / 存储总线、ME 接口与样板供应器都能直接处理气体。
