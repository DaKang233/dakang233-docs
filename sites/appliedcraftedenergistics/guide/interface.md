# ME 气体接口

0.2.0 起，ME 气体接口是 AE2 原版 ME 接口的**气体增强版**：九组「配置槽 + 缓存槽」、逐槽目标数量与目标压力、逐槽传输模式，以及两种专用升级卡。

## 九组配置槽与缓存槽

| | 说明 |
|---|---|
| 上排（配置槽 ×9） | 标记气体种类、目标数量、目标压力与模式 |
| 下排（缓存槽 ×9） | 显示该槽当前缓存；由 AE2 网络按目标数量自动补货 |
| 每槽上限 | **64kGU**（64,000 GU），九槽理论总容量 576kGU |
| 每槽气体 | 只能缓存一种气体 |

接口每 tick 检查九个槽位：低于目标数量就从网络补货；超过目标数量、或槽位未配置时，把多余气体退回网络。目标数量是**缓存上限**，不是累计输出总量——槽位可以反复补货，向外部管网累计供应远超 64kGU 的气体。

::: tip 未配置的槽位
没有标记气体的槽位不会长期缓存：CCB 管道送入的气体会在下一个 tick 被接口收进 ME 网络（与原版 ME 接口"自动识别"的行为一致）。
:::

## 目标压力

每个槽位可以单独设置目标压力（默认 1 atm，未显式配置时显示灰色默认值）。压力与目标数量共同决定槽位的**真实体积**：

```
体积(L) = 目标数量(GU) / 目标压力(atm)
压力   = 当前数量 × 100,000 / 体积
```

因此槽位装满目标数量时，压力恰好等于目标压力；不足时压力更低，CCB 管道会按压差自然流动。槽位容器额定到 CCB 的硬上限 **24 atm**，但正常目标压力最高 **16 atm**（CCB 安全线）。

**接口不会无条件维持压力**：实际供气受缓存数量、外部管网压力、CCB 求解器与流量上限共同约束；ME 网络仍然只以 GasKey + GU 数量管理气体，压力不进入 GasKey。

## 传输模式与逐槽控制卡

默认**所有槽位双向**（BOTH），不需要任何升级卡。

安装 **逐槽控制卡**（`slot_control_card`，最多 1 张）后，每个槽位可以独立设置：

| 模式 | 行为 |
|---|---|
| **输入** | 只允许外部管网 → ME 网络 |
| **输出** | 只允许 ME 网络 → 外部管网 |
| **双向** | 两个方向都允许（默认） |
| **关闭** | 该槽位不参与 CCB 传输（仍参与 ME 补货/回收） |

- 安装卡片时所有槽位保持双向，不改变现有配置；
- 移除卡片后统一回到双向，逐槽设置保留在存档里，重新安装即恢复；
- 未安装卡片时，GUI 不会提供逐槽模式切换。

## 安全阀卡

安装 **安全阀卡**（`safety_valve_card`，最多 1 张）后，槽位压力达到 **20 atm** 时自动泄压：

1. 从槽位取出一小批气体（1,000 GU/t）；
2. 通过 CCB 的 `GasReleaseService` 做一次**真实的径向释放**（`GasReleaseCause.OVERFLOW`）；
3. 只在释放成功后扣除槽内气体，释放失败不会凭空删气；
4. 压力回落到安全范围后停止。

排出的气体产生 CCB 原生环境效果（含推动附近实体），而不是简单删除数量。正常目标压力（≤16 atm）低于泄压阈值，因此不会出现"补气 → 泄压"的循环。

## 气体标记

| 方式 | 说明 |
|---|---|
| 气体样本 | `gas_sample` 物品，右键配置槽写入气体 |
| 气体容器 | 手持 CCB 气罐/容器右键配置槽，读取其中气体写入 |
| AE2 包裹资源 | 配置槽接受 AE2 的 `WrappedGenericStack`（气体键的包裹物品） |

标记后目标数量默认 64kGU，可用滚轮调整。

## 升级卡

接口有 **6 个升级槽**：

| 卡 | 上限 | 作用 |
|---|---|---|
| 速度卡 | 4 张 | 提高每 tick 的网络补货/回收速度 |
| 逐槽控制卡 | 1 张 | 解锁逐槽输入/输出/双向/关闭 |
| 安全阀卡 | 1 张 | 过压真实排气 |

## GUI 操作

| 操作 | 效果 |
|---|---|
| 中键点击配置槽 | 循环该槽模式（需逐槽控制卡） |
| 右键配置槽（手持气体样本/容器） | 标记气体 |
| 滚轮（配置槽上） | 目标数量 ±1,000 GU |
| Shift + 滚轮 | 目标压力 ±1 atm；减到 0 恢复默认 |
| 悬停配置槽 | 显示服务端实际保存的目标数量/压力/模式 |

## 从 0.1.x 升级

- 旧的 8 kL 缓冲罐气体在加载时自动转入**第一个空槽**；九个槽都满时按丢失处理并在日志中记录；
- 旧的单设备模式（导入/导出/双向/关闭）与供给压力设置不再使用，新接口默认全部双向、逐槽可调；
- 0.1.x 的 `gas_interface.bufferVolumeLiters`、`supplyPressureKpa`、`transferRate`、`energyPerKiloGasUnit` 配置项废弃。

::: warning AE2 原版 ME 接口不再缓存气体
0.2.0 移除了旧版给 `ae2:interface` 添加的气体缓存能力。气体应通过本接口（或输入/输出总线、存储总线）进出网络；原版 ME 接口仍可正常用于物品/流体。
:::
