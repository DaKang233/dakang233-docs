# ME 气体接口

ME 气体接口是"网络 ↔ 真实气体世界"的正式接口。它是一台机器方块，会把相邻的
气体储罐 / 管路当作邻居，同时用一只**真实的缓冲罐**与它们交换气体。

![ME 气体接口方块](/interface-block.png)

## 内部缓冲罐

| 参数 | 默认值 | 说明 |
|---|---|---|
| 体积 | 8,000 L | 可在配置里修改 |
| 最大承压 | 24 atm（2.4 MPa） | CCB 的硬上限 |
| 物理容量 | 192,000 GU | 8,000 L × 24 atm |
| 供给压力 | 100 kPa（1 atm） | GUI 可调，每格 100 kPa，上限 1,600 kPa |

六个面使用同一张 16×16 可连接贴图：

![接口贴图三面一致](/interface-textures.png)

"供给压力"指的是**AE 侧把缓冲罐补到多少压力**：调高它，缓冲罐里的气就能顶住更高的管路压力，
从而把气"压"进相邻的高压管；调低它，则只适合低压设备。

## 四种模式

| 模式 | 行为 |
|---|---|
| **导入** | 把缓冲罐里的气体收进 ME 网络 |
| **导出** | 把网络里的气体放进缓冲罐，供相邻管路取走 |
| **双向** | 两个方向都允许 |
| **关闭** | 停止与 ME 网络交换 |

模式按钮在 GUI 顶部，点击循环切换。

## 与 CCB 管路的关系

接口在 CCB 眼里就是一只**普通的气体储罐**：有体积、有压力、遵守质量守恒。
因此：

- CCB 的泵、阀门、管路可以直接把气打进接口，也可以从接口抽气；
- 接口不会凭空产生压力，也不会把相邻储罐压过 16 atm 安全线（供给压力本身可调，但受 CCB 硬上限约束）；
- 当缓冲罐达到当前供给压力时，AE 侧会停止注入，GUI 会显示"阻塞 / 过压"提示。

## 速率与耗电

| 参数 | 默认值 |
|---|---|
| 每 tick 搬运上限 | 1,000 GU/t |
| 待机耗电 | 8 AE/t |
| 搬运耗电 | 1.0 AE / kGU |

全部可在 [配置文件](/guide/config) 中调整。

## GUI 读什么

- 缓冲罐：气体名称 + 存量 / 容量（kGU）；
- 压力：当前压力 / 承压上限（kPa / MPa，和 CCB 的气压表一致）；
- 模式与供给压力；
- 状态提示：过压、阻塞。

::: warning 它不会主动把气推给 AE2 的 ME 接口
ME 接口（AE2 的方块）按 AE2 的设计不"推"东西——相邻的管道或机器来抽。
本模组给 AE2 的 ME 接口注册了 CCB 气体能力，所以 **CCB 的管道可以直接从 ME 接口抽气**；
而 AE2 的输入总线 / 输出总线 / 存储总线 / 样板供应器则通过标准策略直接与 CCB 交互，
不需要接口作为中间层。
:::
