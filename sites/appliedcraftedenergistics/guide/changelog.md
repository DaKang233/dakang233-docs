# 更新日志

## 0.2.2

### 高容量气体元件

- 新增 **1M / 4M / 16M / 64M / 256M** 五档元件，总容量 = 字节数 × 1,000 GU；
- 使用 MEGA 风格档位强调色，同时保留本模组的青绿色外壳；
- 默认配方使用 MEGA Cells 的元件外壳、存储核心和 CCB 气密储罐；
- 默认配方带 `neoforge:mod_loaded` 条件：**只有安装 MEGA Cells 时才加载**；
- 新增配置项 `recipes.enable_mega_cell_recipes`，可移除默认 MEGA 配方，允许数据包提供自定义配方。

### 接口与自动化

- ME 气体接口新增逐槽设置界面：目标数量、目标压力和传输模式；
- 新增**逐槽控制卡**；
- 新增**安全卡**（`safety_valve_card`），危险超压时通过 CCB 真实释放；
- 新增**气体压力卡**（`gas_pressure_card`），安装在 AE2 输入/输出总线上设置目标压力；
- AE2 原生 ME 接口、样板供应器、输入/输出/存储总线重新获得气体支持；
- 安装 AE2-JEI-Integration 时，JEI 的 “+” 可把 CCB 气体输入/输出编码进 AE2 处理样板。

### 稳定性与文档

- 修复气体自动合成在保存并重载世界后丢失样板输出的问题；
- 新增气体存储元件、ME 气体接口与自动化的 GuideME 页面；
- 全部十档气体元件在 GuideME 中按 **G** 可打开对应页面；
- 更新气体样本和新升级卡贴图。

## 0.2.1

- **JEI 拖拽标记**：安装 JEI 时，把 CCB 的气体 ingredient 或气体虚拟物品拖到配置槽即可标记该槽气体；
- 配置槽右键标记现在也支持 CCB 的虚拟气体物品（`VirtualGasItems`）；
- JEI 是可选依赖，未安装时其余功能不受影响。

## 0.2.0

### ME 气体接口重做

- 改为与原版 ME 接口相同的**九组配置槽 + 九组缓存槽**结构；
  每槽目标数量 0–64kGU，目标压力 0–16 atm（容器额定 24 atm）；
  槽位体积按 `目标数量 / 目标压力` 推导，装满时压力恰好等于目标压力。
- 默认**全部双向**；新增**逐槽控制卡**，安装后每槽可独立选择输入 / 输出 / 双向 / 关闭；
  移除卡片后回到统一双向，配置保留。
- 升级槽从 4 个增加到 **6 个**（速度卡 ≤4、逐槽控制卡 1、安全卡 1）。
- 新增**安全卡**：压力达到 20 atm 时通过 CCB 的 `GasReleaseService` 真实释放气体
  （径向 `OVERFLOW`，含环境效果/实体推动），只有释放成功才扣除槽内气体。
- 气体标记：新增 `gas_sample` 气体样本物品与 `gas_id` 数据组件；
  支持手持气体样本/气体容器右键配置槽标记；配置槽也接受 AE2 包裹气体物品。
- 旧版 8 kL 缓冲罐中的气体在升级时自动转入**第一个空槽**；九槽都满时记录日志并丢弃。
- 移除 0.1.x 给 `ae2:interface` 添加的旧气体缓存兼容；0.2.2 已用新的适配器恢复原版接口的气体能力。
- 废弃 `gas_interface.bufferVolumeLiters` / `supplyPressureKpa` / `transferRate` /
  `energyPerKiloGasUnit` 配置项；仅保留 `gas_interface.idlePower`。

### 已知限制

- 输入/输出总线的逐部件目标压力在 0.2.0 尚未实现；0.2.2 由气体压力卡补齐；
- JEI 拖拽标记在 0.2.1 接入；
- 气体 P2P、气体存储元件、总线/存储总线/样板供应器的气体支持保持不变。
