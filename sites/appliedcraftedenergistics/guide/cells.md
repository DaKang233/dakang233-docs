# 气体存储元件

气体存储元件是 CCB 气体进入 ME 网络后的“仓库”。共十档：

| 元件 | AE 字节 | 气体容量（GU） | 相当于 1 atm 下的体积 |
|---|---:|---:|---:|
| 1k | 1,024 | 1,024,000 | 1,024 m³ |
| 4k | 4,096 | 4,096,000 | 4,096 m³ |
| 16k | 16,384 | 16,384,000 | 16,384 m³ |
| 64k | 65,536 | 65,536,000 | 65,536 m³ |
| 256k | 262,144 | 262,144,000 | 262,144 m³ |
| 1M | 1,048,576 | 1,048,576,000 | 1,048,576 m³ |
| 4M | 4,194,304 | 4,194,304,000 | 4,194,304 m³ |
| 16M | 16,777,216 | 16,777,216,000 | 16,777,216 m³ |
| 64M | 67,108,864 | 67,108,864,000 | 67,108,864 m³ |
| 256M | 268,435,456 | 268,435,456,000 | 268,435,456 m³ |

![气体元件与 AE2 元件样式对比](/cell-style.png)

换算契约：**1 AE byte = 1,000 GU**，而 `1 GU = 100 kPa 下的 1 升气体`。
所以元件容量（GU）除以 1,000 就是它占用的 AE 字节数，也等于“多少立方米的常压气体”。

## 元件是什么、不是什么

- 元件**只保存气体的数量**，不保存气压；把同一只元件从 ME 驱动器里拿出来、放进去，气压不会“变化”，
  因为它本来就没有气压这个概念。
- 元件不承担 CCB 的过压 / 破裂机制；气体进出网络的压力由
  [ME 气体接口](/guide/interface) 和 [气体 P2P 隧道](/guide/p2p) 背后的真实容器负责。
- 每种气体都会占用一部分字节（与 AE2 流体元件一致），所以“存得下多少种”和“存得下多少量”是两回事。

## 高容量档与 MEGA Cells

1M–256M 元件本身在所有安装中都会注册，但它们的**默认配方以 MEGA Cells 为前置**：

- 使用 `megacells:mega_item_cell_housing`；
- 使用 `megacells:cell_component_<档位>`；
- 另加 CCB 气密板 / 气体罐和 1–2 个气密储罐。

配方文件带 `neoforge:mod_loaded` 条件，因此**只有安装 MEGA Cells 时，默认的 1M–256M 配方才会加载和显示**。
配置项 `recipes.enable_mega_cell_recipes` 可以移除这些默认配方；数据包也可以提供自定义配方。
详见 [配置文件](/guide/config)。

## 放入网络

把元件放进 **ME 驱动器**或 **ME 箱子**即可被网络读写。空元件可以用 AE2 的方式拆解回收。

## 终端显示

气体在终端里按气体名排序，图标是按气体颜色绘制的“雾气”图标，数量以 **kGU** 显示
（1 kGU = 1,000 GU）。与物品 / 流体混在同一个终端里，一次搜索即可。

## 升级槽

元件有 **5 个升级槽**，在**元件工作台**里安装：

- AE2 原生卡：反相卡、均分卡、溢出销毁卡；
- 气体专属卡：高压卡、扩容卡、多类型卡、泄压阀卡。

装卡后元件的**字节上限**会变化，因此终端里显示的容量会变大，这不代表元件“降级”——
详见 [元件升级卡](/guide/upgrades)。

## 游戏内教程

全部十档元件都登记在 GuideME 的 `item_ids` 中。把鼠标放在任意气体元件上，按 **G** 即可打开本页。

::: tip 分区
和物品元件一样，气体元件也支持在元件工作台里填写分区。分区决定它接受哪些气体；
反相卡会反转分区列表的含义（白名单 ⇄ 黑名单）。
:::
