# 与 AE2 原生设备互通

本模组不添加新的总线、线缆或终端。它注册 AE2 的行为策略，并给原版 ME 接口补上气体能力，
于是 **AE2 原生设备直接获得气体能力**：

| AE2 原生设备 | 与 CCB 交互方式 | 本模组提供的钩子 |
|---|---|---|
| **输入总线** | 从相邻气体储罐 / 机器抽取气体进入网络 | `StackImportStrategy` + 气体压力卡 |
| **输出总线** | 把网络里的气体压入相邻储罐 / 机器 | `StackExportStrategy` + 气体压力卡 |
| **存储总线** | 把相邻气体储罐当作 ME 存储（可读写） | `ExternalStorageStrategy` |
| **样板供应器** | 把样板产物中的气体推入相邻机器；从网络取气作为原料 | `ExternalStorageStrategy`（AE2 的 `PatternProviderTargetCache` 使用它） |
| **ME 接口** | 原版 `ae2:interface` 的槽位以固定 100 kPa 容器暴露给 CCB 管道，管道可直接抽气 | `AeInterfaceGasCompat` |
| **终端 / 合成 / 自动合成** | 气体作为一等资源参与存储、排序、合成请求 | `AEKeyType` + 存储元件 |

## 总线上的气体压力卡

在 **输入总线 / 输出总线** 中安装 `gas_pressure_card` 后，可以为该总线设置气体目标压力：

- 输出总线只输出到目标压力；
- 输入总线只在外部压力高于目标压力时抽取；
- 右键循环预设，潜行右键回退。

## 样板与 JEI

- AE2 处理样板可以写气体输入/输出，样板供应器会自动从网络取气或把气体推入目标机器；
- 安装 **AE2-JEI-Integration** 后，在 JEI 里对带 CCB 气体的处理配方点击 **+**，可把气体输入/输出写进处理样板；
- 标准 AE2 样板只保存气体类型与数量，**不保存目标压力**；压力仍由机器/容器决定。

## 典型工厂布局

1. **锅炉蒸汽** → 管路 → ME 气体接口（导入模式）→ 网络；
2. 网络里的气体 → 输出总线 + 气体压力卡 → 远处的 CCB 机器；
3. 自动合成：样板里写气体原料 / 产物，样板供应器会自动从网络取气或把气体推入目标机器；
4. 需要跨越长距离时，用 [气体 P2P 隧道](/guide/p2p) 替代长管路。

## 不需要的东西

- 不需要“气体总线”：物品总线在本模组存在时就是气体总线；
- 不需要“气体终端”：现有终端会显示气体条目；
- 不需要为原版 ME 接口单独配置：适配器会自动把其槽位暴露给相邻 CCB 管道。

## 兼容性说明

本模组只依赖 AE2 的公开 API（`appeng.api.*`）与 CCB 的公开 API（`net.ty.createcraftedbeginning.api.*`），
不向它们注入任何 mixin。已与 Applied Pneumatics 1.0.9 + PneumaticCraft 8.2.24 在同一整合包中启动验证。
