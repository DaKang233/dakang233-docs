# 安装与升级

FurinaChronicle 优先支持 Windows 和 Android。请以项目正式发布公告中提供的下载地址、平台要求和包说明为准。开发构建与验收构建可能使用不同的数据目录或应用标识。

## Windows

1. 下载发布公告中标为 Windows x64 的压缩包。
2. 解压到一个独立目录，打开 `FurinaChronicle.Windows.exe`。
3. 已使用过旧版时，按应用内提示校验和备份现有数据，再确认接管。需要联网刷新时，按提示重新授权游戏通行证。

升级时先退出应用，再解压到新的版本目录。涉及数据库升级时，保留升级前备份，并以该发行版的回退说明为准。

## Android

从项目公告下载与你的设备和发行渠道匹配的 APK。Android 可能要求授权当前浏览器或文件管理器安装应用。

升级前先导出档案备份。若系统拒绝覆盖安装，核对新旧包使用的应用标识、签名和版本。保留旧应用，直到确认已有可读取的备份。

## 开始使用

打开档案与账号管理，创建或选择用于保存记录的档案。导入本地文件可以独立进行；使用游戏账号在线刷新时，在用户页选择通行证和对应的角色。
