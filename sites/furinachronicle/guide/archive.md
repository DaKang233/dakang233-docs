# 备份与迁移

Furina Archive 是跨端逻辑档案。它保存所选范围内、当前格式支持的档案和历史记录。游戏登录凭据与设备专属设置不随备份迁移；换机后可在新设备重新授权游戏账号。

## 从 Windows 迁移到 Android，或反向迁移

1. 打开源设备的备份与恢复功能，选择要导出的档案范围。
2. 将生成的备份文件复制到目标设备可通过系统文件选择器访问的位置。
3. 在目标设备选择该文件，等待校验，再查看目标映射、变更和冲突。
4. 按预览确认恢复。恢复后重新打开应用，核对目标档案的账号、记录数和历史内容。

## 合并与范围替换

**合并**适用于保留目标设备已有资料并补充历史；仔细核对已有档案及账号的映射。

**范围替换**适用于明确希望用备份替换指定档案、账号或领域的情况。先确认影响范围及恢复点提示，再提交。范围替换使用专门的恢复机制，普通撤销历史无法代替恢复点。

## 管理备份副本

本地删除只处理应用能管理的本机数据。用户另存的文件和其他设备上的副本，应在对应位置管理。分享导出文件前请检查文件所含的个人游戏记录。
